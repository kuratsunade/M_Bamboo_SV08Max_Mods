## Restore templates

`release/restore_templates/` contains exact release-owned stock templates for destructive/replacement transformations:

- `stock_homing_override.cfg`
- `stock_g28.cfg`
- `stock_clean_nozzle.cfg`

Config files have **no persistent whole-file backup**. Full restore reverses managed transformations and leaves unrelated user changes intact.

## Backend backup policy

The only persistent backend backup is:

```text
/home/sovol/klipper/klippy/extras/mb_bak/
```

It contains original pre-M_Bamboo Python files plus `MANIFEST.json`, is created once, and is never overwritten. Legacy `.mb_baseline` files are migration input only and are trusted only by exact known-stock SHA256. For recognized M_Bamboo lineage, a missing or polluted legacy baseline may fall back to Sovol's factory mirror only when the mirror independently matches an exact known-stock SHA256. RC4 creates no `.last_mb_*` or timestamp backup series.

## Transaction rollback

Installer writes are staged with an immediate pre-transaction copy under:

```text
/tmp/M_Bamboo_SV08MAX.*
```

The temporary transaction directory is removed after success or after a confirmed successful rollback. If automatic rollback itself fails, the snapshot is retained and its path is reported for manual recovery. It is not normal persistent version history.

Healthy-path hardware validation includes repeated homing/contact/nozzle-clean/Z-calibration, QGL, adaptive rapid mesh, final XY re-home, a complete slicer-driven START_PRINT, a real cube print, END_PRINT including the stock `clear_plr` cleanup hook, and post-print Eddy status. The latest recorded post-print session reached 30 clean pre-arm checks with zero transport faults/recoveries/quarantines.

Natural fault-path evidence now includes one naturally occurring raw-34 (`I2C_BUS_NACK | I2C_BUS_BUSY`) active contact-probe event that safely aborted the transaction, invalidated Z trust, force-quarantined the LDC stream, passed explicit no-motion recovery checking, completed one armed fresh Safe Home `G28`, returned to `HEALTHY`, and continued into printing without firmware reset. The remaining RC limitation is continued repeated natural-fault soak and long-term field confidence, not an unobserved recovery mechanism.


## RC4 scope exclusions

- PLR is not included in RC4.
- GSL-R1 is not included in RC4.
- Generic historical downgrade is not implemented by the RC4 installer; use Full Restore, then the target historical release installer.
- Hardware Cooling is packaged as an explicit hardware-dependent feature and is never included by `all`.
- Diagnostics is a formal feature and is included by `all`; installation alone does not execute stress tests.
